## 🎨 MARKA DETAYLARI

**Ana Renkler:**
- **Orange (Primary):** #FF6000, #CC4E00 (aksent)
- **Navy (Dark):** #0F2040, #0A1628 (default)
- **White/Light:** #FFFFFF (light backgrounds)

**Tasarım Stili:**
- Modern, minimal, geometric + organic fusion
- Apple SF Symbols + Feather Icons tarzı
- Stroke-based (fill değil), 2px stroke
- Rounded corners (15-25% radius)
- Max 4-5 şekil per icon (basit, okunabilir)

**Konsept:**
- Sosyal sorumluluk (insancıl, sıcak, güven verici)
- Rehabilitasyon ve yeniden başlama (umut, pozitif momentum)
- Modern ama erişilebilir (48px'te net görülmeli)

## 📞 SORU-CEVAP

**S: İkonlar kaç dakika sürer?**  
C: ChatGPT ~10 dakika, entegrasyon ~30 dakika = 40 dakika toplam

**S: Figma'ya ihtiyacım var mı?**  
C: Opsiyonel. SVG manuel oluştur veya Figma'da refine et. ChatGPT her iki seçeneğe export yapabilir.

**S: React-icons'ları tamamen kaldırmalı mıyım?**  
C: Evet. Custom icons'lar size azaltır (~10% bundle reduction) ve marka uyumlu görünür.

**S: SVG'ler mobile'de görünecek mi?**  
C: Evet, responsive Tailwind classes ile (w-4 h-4, w-6 h-6, vb)

**S: Animasyon ekleyebilir miyim?**  
C: Evet, Tailwind animation classes: animate-bounce, animate-spin, vb

**S: Performance problemi olur mu?**  
C: Hayır, SVG'ler küçük (~1-2KB her biri) ve static.
